# 设计库来源与提取要点

以下是候选来源，不是固定可用性或全球排名。每次运行重新验证页面、重定向和公开访问情况，按用户主题选择来源；不能把过去的错误状态当作永久限制。

| 来源 | 入口 | 适用内容 | 注意点 |
|---|---|---|---|
| Siteinspire | https://www.siteinspire.com/ | 品牌、作品集、排版、艺术、电商 | 列表混有作者/机构资料页。仅把实际网站案例计入；从详情页标题外链、Categories 和 Published 提取。 |
| Minimal Gallery | https://minimal.gallery/ | 简洁风格、个人站、机构、SaaS | 区分案例与 Sponsored。详情通常有原站外链、Type、Published；不将 Credits 中的开发者网站作为案例原站。 |
| One Page Love | https://onepagelove.com/inspiration | 单页、作品集、落地页 | 部分列表有直接原站链接，部分分页没有，应进一步读详情或留空。页码和 HTML 结构可能变化，不能把解析失败当成没有案例。 |
| Lapa Ninja | https://www.lapa.ninja/ | SaaS、营销、产品落地页 | 首页可能同时展示推荐位、广告、最新案例、OG 图、模板。优先采集正式案例列表；保留实际出处和推广属性。 |
| Awwwards | https://www.awwwards.com/websites/ | 交互、创意、获奖网站 | 仅在来源明确给出奖项时记录奖项；访问可能超时或受限。 |
| Land-book | https://land-book.com/ | 品牌、电商、落地页 | 公开可读取范围可能有限；403 时记录限制并切换来源。 |

采集策略：先少量验证字段，再扩展列表或分页。数量是去重后的目标，扩展同一来源前检查当前来源分布。列表首页样本不足时可用详情页的关联案例继续发现，但不能将关联条目直接当成已提取完整详情。

网页工具的展示文本有时只包含外链域名，没有完整 href。使用其 click/open 能力解析外链，保存确切 URL；原站返回错误时仍可保留工具明确报告的请求目标，并把 link_status 标为错误或未验证。若工具没有报告确切目标则留空。

不沿用其他会话的网页引用 ID、抓取日期、用户目录或代理配置。当前页面发生变化时调整提取方式，附带导出脚本与来源网页结构无关。
